# TugasKu Landing Page

Landing page resmi aplikasi TugasKu untuk memperkenalkan fitur dan menyediakan tautan unduhan APK Android.

## Isi proyek

- `index.html` — halaman landing page utama.
- `css/style.css` — gaya visual landing page.
- `css/preview.css` — bingkai dan tampilan screenshot aplikasi.
- `js/script.js` — navigasi anchor sederhana.
- `images/app-preview.png` — screenshot Beranda aplikasi.
- `images/tugasku-logo.png` — logo TugasKu.
- `downloads/tugasku-arm64-v8a.apk` — APK Android untuk diunduh.

## Menjalankan lokal

Buka terminal pada folder proyek, lalu jalankan:

```bash
python -m http.server 8080
```

Buka `http://localhost:8080` pada browser.

Landing page ini bersifat statis dan tidak memerlukan Firebase, database, Bootstrap, jQuery, atau proses build tambahan.
